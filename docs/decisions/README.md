# Architecture decision records

ADRs capture consequential Orion decisions and the evidence behind them.

## Status values

`proposed`, `testing`, `accepted`, `rejected`, or `superseded`.

Copy `0000-template.md`, assign the next number, and keep rejected or
superseded decisions in the repository.
